Agent Ready WP

Injects @graph JSON-LD so AI agents can understand your WordPress site.

Free • WordPress 6.9+ • No dependencies
Download agent-ready-wp.zipLatest release • install-ready

Install

  1. In WordPress, go to Plugins → Add New → Upload Plugin.
  2. Choose the downloaded agent-ready-wp.zip and click Install Now.
  3. Click Activate. Agent Ready WP starts emitting JSON-LD immediately.
