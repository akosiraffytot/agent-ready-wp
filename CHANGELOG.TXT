=== Agent Ready WP Changelog ===

= 1.2.1 =
* Fixed: Organization geo latitude/longitude are now emitted as clean text values (e.g. "34.85698") instead of floats, so no long decimal precision noise appears on servers with a high serialize_precision setting. schema.org's latitude/longitude accept Text.

= 1.2.0 =
* New: multi-type Organization selector — several Schema.org subtypes can be selected at once (e.g. LocalBusiness + ClothingStore); the Organization node emits `@type` as an array and the settings sections union across all selected types.
* New: field clusters for niche types — dining (servesCuisine, acceptsReservations, hasMenu), hospitality (starRating, numberOfRooms, checkinTime, checkoutTime, petsAllowed), medical (medicalSpecialty, availableService), education (department, alumni), civic & community (affiliation, sport).
* New: "Location & Local Information" section now also applies to education/civic types, NGOs, news media, and corporations.
* New: Custom JSON-LD escape hatch — name|JSON lines merged into the Organization, WebSite, and content nodes, or appended to the graph; {home} placeholder, # comments, duplicate names become arrays, invalid lines dropped with a notice.
* Fixed: settings toggles (acceptsReservations, petsAllowed) now emit correctly (strict string comparison against an int-stored option).
* Fixed: author profile schema save now explicitly re-verifies the profile form nonce (defense in depth; core already verifies it before these hooks fire).
* Fixed: module toggle no longer reads a possibly-missing `enabled` request key without a guard.
* Improved: full WordPress Coding Standards pass — phpcbf formatting (line endings, alignment), docblocks on all settings field/section renderers, translators comments on placeholder strings; `phpcs --standard=WordPress` reports 0 errors and 0 warnings on all 6 plugin files.

= 1.1.0 =
* New: organization type selector — 54 Schema.org subtypes (LocalBusiness/MedicalBusiness, non-profit, news media, corporation, online business, and store types) with conditional settings sections.
* New: Organization identity fields: legalName, slogan, taxID, vatID, foundingDate, founder, areaServed, contactPoint (telephone, email, contactType, availableLanguage), sameAs, knowsAbout.
* New: LocalBusiness data: PostalAddress, GeoCoordinates, priceRange, openingHoursSpecification (parsed from lines like "Mo-Fr 09:00-17:00").
* New: niche fields: nonprofitStatus, publishingPrinciples/ethicsPolicy/correctionsPolicy/diversityPolicy, tickerSymbol, paymentAccepted/currenciesAccepted/hasMerchantReturnPolicy.
* New: per-post Service schema (serviceType + offers/price) from the post editor.
* New: automatic BreadcrumbList on pages (ancestors), posts (top-level category), and archives; skipped when fewer than 2 items.
* New: "Disable Third-Party JSON-LD Schema" toggle suppresses Yoast/Rank Math/AIOSEO JSON-LD while the module is active.
* New: developer filters agent_ready_organization_node (per-node) and agent_ready_json_ld_graph (full graph, incl. settings preview).
* New: organization logo selectable from the WordPress Media Library.
* Improved: validator `?code=` prefill now falls back to URL-based validation (`#url=`) when the encoded payload exceeds 14 KB instead of opening an empty validator.
* Fixed: settings pages (general + JSON-LD) now render the "Settings saved." notice via settings_errors().

= 1.0.4 =
* Updated: plugin updates now download the install-ready zip attached to the GitHub release, so the plugin folder stays free of repository-only files (index.html, .github, AGENTS.md).

= 1.0.3 =
* New: the admin bar "Validate Schema" menu now has a hover submenu with two URL-based validators — Schema.org (via URL) and Google's Rich Results Test — in addition to the existing code-prefilled schema.org validator. The URL-based links validate the live page (works only for publicly reachable URLs).

= 1.0.2 =
* Fixed: "Validate Schema" admin bar button now opens validator.schema.org with the prefilled JSON-LD even on sites with Formidable Forms active (the link is now built server-side, with no JavaScript dependency).
* Fixed: the JSON-LD prefilled into the validator keeps its per-line formatting (newlines are no longer stripped by WordPress URL escaping).

= 1.0.0 =
* Initial release.
* Emits a single JSON-LD @graph for AI-agent readiness: Organization, WebSite, Person (single posts), content nodes, archives/home CollectionPage + ItemList, and custom post type support.
* Dashboard with one-click module toggles (JSON-LD active; llm_txt, ai_robots, woocommerce coming soon).
* Post/page schema overrides (WebPage, AboutPage, ContactPage, FAQPage) with FAQ validation.
* Author profile fields (jobTitle, sameAs) for Person schema.
* Live JSON-LD preview with Copy and Validate actions on the settings page.
* Automatic updates from GitHub (Plugin Update Checker).
